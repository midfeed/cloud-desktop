# Security Policy

Midfeed takes the security of the Midfeed Cloud desktop application seriously. We
value the work of security researchers and users who help us keep our product and
customers safe.

## Supported Versions

Only the latest released version of Midfeed Cloud receives security updates. The
application updates itself automatically, so please ensure you are running the most
recent build available on the
[Releases](https://github.com/midfeed/cloud-desktop/releases/latest) page.

## Reporting a Vulnerability

Please report suspected security vulnerabilities **privately**. Do **not** open a
public GitHub issue or otherwise disclose the issue publicly until it has been
resolved.

Email **dev@midfeed.com** with:

- A description of the vulnerability and its potential impact.
- Clear steps to reproduce, including the affected version(s).
- Any relevant logs, screenshots, or proof-of-concept material.

## What to Expect

- **Acknowledgement** of your report within 3 business days.
- **Triage and assessment**, including a severity rating and remediation plan.
- **Coordinated resolution**, with notification once a fix has been released.

We ask that you act in good faith, avoid privacy violations and service
disruption, and allow us reasonable time to remediate an issue before any public
disclosure.

## Contact
